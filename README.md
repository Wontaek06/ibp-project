# IBP 보유 분류군의 서식 환경 모델링
### GBIF 좌표 편향성 분석 및 PAMC 기반 교정

2026 극지 빅데이터-인공지능 활용 경진대회 · 데이터 분석 부문 · 팀 ColdFold

본 저장소는 예선 제출 분석보고서에 수록된 모든 수치·표·그림을 재현하는 코드와 결과 데이터를 포함한다.

> ⚠️ **보고서 제출 이후 좌표 처리 오류 4건을 수정하였으며, 그 결과 어류 패널의 환경 변수
> 15~17 / 18종의 값이 변경되었다.** 또한 계통 통제 교차검증 결과 AFP 타입에 대한 예측 주장은
> 성립하지 않는다. 보고서와 어긋나는 지점은 **[§9 정오표](#9-정오표-errata)** 에 전부 정리하였으며,
> 수치는 저장소의 결과 CSV 가 최신·정정본이다.

`python -m src.pipeline` 은 어류 패널(18종)과 계통 통제 교차검증까지 수행한다.

python -m src.fetch_pfam
cd-hit -i data/pfam11999_proteins.fasta -o data/pfam11999_nr90.fasta -c 0.9 -n 5
python -m src.expand_eda
python -m src.expand_env        # 속 단위 서식지 온도 (장시간, 재개 가능)

# 3단계 — PAMC 균주 단위 교차검증 (장시간, 재개 가능)

python -m src.build_report_assets

`expand_env` 와 `kpdc_crosscheck` 는 항목마다 결과를 append 하고 완료분을 건너뛰므로,
중단되어도 다시 실행하면 이어서 진행된다.
CD-HIT 는 별도 설치가 필요하다: `conda install -c bioconda cd-hit` 또는 `brew install cd-hit`

### 산출물

실행이 완료되면 다음이 생성된다.

- `data/` — 통합 결과 및 통계 요약 CSV
- `figures/` — 보고서 수록 그림 (11장)
- `REPORT_ASSETS.md` — 그림 11장 + 표 7개를 캡션과 함께 모은 문서.
  모든 표는 `data/` 의 CSV 에서 직접 계산되므로 본문 수치와 어긋나지 않는다.

### 캐싱

외부 API 응답은 `.cache/` 에 저장되어 재실행 시 재호출하지 않는다.
첫 실행은 API 호출로 수 분이 소요되며, 이후에는 수 초 내에 완료된다.

```python
from src.cache import clear_cache
clear_cache()               # 전체 초기화
clear_cache("bio_oracle")   # 특정 원천만 초기화
```

환경변수 `IBP_NO_CACHE=1` 을 지정하면 캐시를 사용하지 않는다.
수집 함수의 반환 구조를 변경한 경우에는 캐시를 초기화한 뒤 실행한다.

## 6. 분석 파이프라인

```
시드 목록 / PF11999 도메인 질의
        │
        ├─ 서열 수집 (UniProt · 수탁번호 고정)
        ├─ 분류 매칭 (계통 힌트 기반)
        ├─ 출현 좌표 수집 (GBIF)
        ├─ 대표점 선정 (분포중심 기준)
        ├─ 환경 매핑 (해양: Bio-ORACLE / 육상: ERA5)
        ├─ 구조 조회 (AlphaFold DB)
        └─ 특성 산출 → 통계 검정 → 시각화
                │
                ▼
        결과 CSV · 그림
```

### 주요 설계 결정

파이프라인의 좌표 처리 규칙은 보고서 3.2~3.3절에 서술한 네 건의 편향 검토 결과를
반영한 것이다.

1. **관측월 필터를 적용하지 않는다.** 계절 극값은 환경 레이어(연중 최저수온)가
   담당하므로 좌표를 월로 거르면 극지 현장조사의 계절 편중이 유입된다.
2. **대표점은 분포 중심으로 산출한다.** 분포 꼬리는 미아 개체 기록에 지배되어
   상시 서식 환경을 대표하지 못한다. 서식 한계 분석을 위해 꼬리 위도는 별도 보존한다.
3. **경도 ±180 구간을 이어붙인다.** 남극 환극분포종은 날짜변경선 부근에 위치하며,
   경도 범위를 자르면 환경값이 전 레이어에서 결손된다.
4. **서식지 판정에는 반경 탐색을 쓰지 않는다.** 반경 탐색을 허용하면 육상 좌표가
   인근 해양 셀의 수온을 받아 서식지가 오분류된다.
5. **해양 수온과 육상 기온을 하나의 변수로 합치지 않는다.** 해수는 결빙점에서
   하한이 막히지만 육상 기온은 그렇지 않다. 결과 테이블에서 `habitat` 컬럼으로 구분한다.

### 계통 통제 교차검증

AFP 타입은 계통과 강하게 교란되어 있다. 노토테니아과 4종이 전부 AFGP, 가자미과 2종이
전부 Type I, 등가시치과 2종이 전부 Type III 이다. 따라서 Leave-One-Out 은 제외된 종의
근연종이 학습셋에 남아, 서식 환경을 학습하지 않고 계통을 식별하는 것만으로 정답을 맞출 수
있다. 과(family) 단위로 제외하면 이 경로가 차단된다.

| 변수 집합 | LOO | 과 holdout | 다수클래스 baseline |
|---|---|---|---|
| 환경만 | 0.222 | 0.056 | 0.444 |
| 서열만 | 0.600 | 0.300 | 0.300 |
| 환경 + 서열 | 0.300 | 0.200 | 0.300 |

**계통을 통제하면 어떤 변수 집합도 다수클래스 baseline 을 넘지 못한다.** 환경 변수만으로는
Leave-One-Out 에서조차 baseline 에 미치지 못한다.

따라서 본 데이터는 환경 변수로 AFP 타입을 예측한다는 주장을 뒷받침하지 않으며, AFP 타입은
계통적 산물로 보는 것이 타당하다. 본 분석이 뒷받침하는 명제는 타입 예측이 아니라
**IBP 보유 여부가 한랭 서식지와 연관된다**는 것이며, 이는 1단계 스파이크에서
Mann-Whitney p=0.0027 (U=0, 순위 완전 분리) 로 지지된다.

산출물: `data/phylogeny_cv.csv`, `figures/model_phylogeny_control.png`

## 7. 데이터 및 방법상의 한계

보고서 6.1절에 상세히 기술하였으며, 코드 사용자가 알아야 할 사항은 다음과 같다.

- **`data/seed_species.csv` 는 파이프라인이 생성하는 파일이 아니라 문헌 검토로
  작성한 입력 파일이다.** 모든 그룹 비교가 이 라벨에 의존한다. 13종 전부에 대해
  UniProt 등재명과 교차확인을 완료하였으며, 그 과정에서 *Gadus morhua* 1건을
  AFGP에서 Type IV로 재분류하였다.

- **전지구 출현 좌표는 미생물의 극지성을 반영하지 못한다.** 보고서 4.5절에서
  576 균주 규모로 정량화한 결과이며, 해당 좌표에 기반한 환경값은 거친 스크리닝
  지표로만 제시하고 정량적 주장에는 사용하지 않는다.

- **AFGP는 UniProt 등재 형태가 성숙 펩타이드와 전구체로 혼재한다**(17 aa ~ 790 aa).
  길이 의존 지표(pI, 불안정지수)는 서로 다른 대상을 비교하게 되며, 조성 비율
  지표(Ala·Thr 비율)가 상대적으로 견고하다.

- **pLDDT 기반 규칙성 지표는 검증된 구조생물학 지표가 아닌 예비적 휴리스틱이다.**

- **RandomForest 결과는 변수 중요도 확인 용도이며 예측 성능을 주장하지 않는다.**
  어류 패널은 그룹당 1~8종으로 신뢰구간이 넓다.
  계통 통제 교차검증(§6)에서 확인된 바와 같이, 과 단위 제외 시 어떤 변수 집합도
  다수클래스 baseline 을 넘지 못한다.

- **PAMC 는 극지 기관이 극지에서 수집한 컬렉션이므로 표본 자체가 극지 편향이다.**
  DUF3494 보유 속이 극지에 분포한다는 확인 근거는 되지만, 극지에만 분포한다는 주장의
  근거로는 사용할 수 없다.

- **PAMC 원본에 좌표가 없는 균주가 125건 있다**(King George Island 37, Ross Sea 29,
  Mountain Rwenzori 43 등). 권역 분류는 지명 문자열로 가능하나 좌표 기반 분석에서는
  제외되며, 추정 좌표로 보완하지 않았다.

## 9. 정오표 (Errata)

보고서 제출 이후 좌표 처리 오류를 수정하고 계통 통제 검증을 추가하는 과정에서, 보고서
서술과 어긋나는 지점이 확인되었다. 아래 항목은 **저장소의 결과 CSV 가 정정본**이다.

### E1. 어류 패널 환경 변수 수치 변경

§6 "주요 설계 결정" 의 네 건(관측월 필터, 대표점 정의, 경도 ±180 이어붙이기, 서식지
판정 반경)을 반영한 결과 **환경 변수 15~17 / 18종의 값이 변경**되었다. 위도·표층최저수온·
저층수온·해빙두께가 모두 해당되며, 그 위에서 산출되는 Kruskal-Wallis·Dunn·부트스트랩
신뢰구간·변수 중요도도 함께 변경된다.

서열·구조 지표(`ala_pct`, `thr_pct`, `gravy`, `pI`, `instability`, `plddt`)는 **0 / 18 로
불변**이다. 좌표에 의존하지 않는 값이므로 예상된 결과이며, 수정이 의도한 범위에만
적용되었음을 보여준다.

대표 사례로 *Dissostichus mawsoni* 는 경도 -179.6° 에 위치하여 수정 전에는 모든 환경
레이어가 결손이었으나, 수정 후 표층최저수온 -1.965 °C 로 산출된다.

→ 갱신 기준: `data/final_merged.csv`, `data/stats_summary.csv`, `figures/env_*.png`

### E2. AFP 타입 예측에 관한 서술

계통 통제 교차검증(§6) 결과, 과 단위 제외 시 어떤 변수 집합도 다수클래스 baseline 을
넘지 못한다. 환경 변수만으로는 Leave-One-Out 에서조차 baseline(0.444)에 미치지
못한다(0.222).

따라서 **환경 변수가 AFP 타입을 설명한다는 취지의 서술은 성립하지 않는다.** 본 분석이
뒷받침하는 명제는 **IBP 보유 여부와 한랭 서식지의 연관**(p=0.0027)이다.

### E3. PAMC 산출 수치

`python -m src.kpdc_crosscheck` 재실행 결과가 보고서 4.5절 수치와 부분적으로만 일치한다.

| 항목 | 보고서 | 저장소 재실행 |
|---|---|---|
| 대조표 | 576 균주 | **574 균주** |
| 좌표 | 479 | **449** |
| 채집 지점 | 95 | **38** |
| 속별 위도 | 45 | **38** |

- 좌표 차이는 PAMC 원본에 좌표가 없는 균주 125건에 기인하며, 추정값으로 보완하지 않았다.
- 채집 지점 95 는 시도한 어떤 정의로도 재현되지 않았다: 지명 문자열 38 / 좌표쌍 30 /
  지명+서식지 59 / sampling site 29.

§3 의 데이터 출처 표에 기재된 "576 균주 / 479 좌표 / 95 채집 지점" 은 보고서 기준 수치이며,
저장소 재현 값은 위 표를 따른다.

### E4. 보고서 4.6절 해양 지점 수

보고서 본문의 "47곳" 과 동일 문단의 "북극해 59 + 남극해 30(=89)" 이 서로 일치하지 않는다.
저장소 재실행 값은 아래와 같으며 양쪽 어느 값과도 일치하지 않는다.

| 기준 | 값 |
|---|---|
| 해양 채집 **지점** 수 | 17 (남극 9 · 북극 7 · 기타 1) |
| 해양 **균주** 수 | 196 (북극 149 · 남극 23 · 기타 24) |

→ 인용 기준: `data/pamc_sites.csv`, `data/pamc_coordinates.csv`

### 정오표 관련 참고

E3·E4 는 보고서 작성에 사용된 원본 스크립트가 저장소에 포함되어 있지 않아, 집계 정의의
차이를 직접 대조할 수 없는 상태이다. 현재 `src/kpdc_crosscheck.py` 는 보고서 수치에 맞추지
않고 실행 결과를 그대로 산출하도록 작성하였다. 교차검증의 목적상 목표값을 전제하고 집계
기준을 조정하면 검증으로서의 의미가 사라지기 때문이다.
